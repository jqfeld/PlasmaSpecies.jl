Gases and masses

The Gas of a Species is its chemical identity, independent of charge and internal state. A gas label is resolved by Gas(label) in three steps:

  1. REGISTERED_GASES — non-formula labels. Only "e", giving Electron.
  2. parse_formula — a chemical formula, giving a Molecule that knows its composition and therefore its mass.
  3. StringGas — a label that resolves to neither. It parses, prints and round-trips, but has no composition and no mass.

There is no registration step: any formula built from the nuclide tables is a usable gas.

julia> using PlasmaSpecies
julia> gas(Species("CO2"))CO₂
julia> gas(Species("SF6"))SF₆
julia> gas(Species("Xyz"))Xyz

Formula syntax

parse_formula accepts three spellings.

Natural abundance. Bare element symbols, optionally with counts. Each resolves to an Element, i.e. the standard atomic weight — N2 is 2 × 14.007 u, which is what LoKI-B and BOLSIG+ assume for a bulk gas.

julia> composition(gas(Species("CH4")))(C => 1, H => 4)

A single isotopic segment. A mass number in front: "14N2", "16O".

ExoMol iso_slug. Segments joined by -, matching the spelling ExoMol.jl uses, so species strings line up with load_isotopologue slugs.

julia> gas(Species("16O-1H"))¹⁶O¹H
julia> gas(Species("12C-16O2"))¹²C¹⁶O₂
julia> string(gas(Species("16O-1H")))"16O-1H"

Two display forms: print/string is plain ASCII and preserves the written order, so a species round-trips through its string; show is the pretty form with sub- and superscripts.

Two-letter symbols match greedily, per the usual chemical convention, and case is significant:

julia> gas(Species("CO"))   # carbon monoxideCO
julia> gas(Species("Co"))   # cobaltCo

A formula that does not resolve — unknown symbol, unknown isotope, leftover text — falls back to StringGas rather than throwing. Note that the species parser only accepts letters, digits and - in the gas token, so a label like "my_gas" is a parse error, while "mygas" is a StringGas.

Composition and equality

A Molecule stores the composition twice: as written, and canonical (repeated nuclides merged, sorted by atomic and mass number). == and hash use the canonical form, so OH and HO are the same gas and the same Dict key, while display keeps what was written.

julia> gas(Species("OH")) == gas(Species("HO"))true
julia> composition(gas(Species("H2O")))(H => 2, O => 1)
julia> canonical_composition(gas(Species("H2O")))(H => 2, O => 1)

Masses

mass is in kilograms throughout. For a species, the electrons implied by the charge are added or removed.

julia> mass(Species("CO2")) / PlasmaSpecies.U_KG   # in daltons44.009
julia> mass(Species("28Si-16O")) / PlasmaSpecies.U_KG43.97184115422001
julia> mass(Species("N2[+]")) == mass(Species("N2")) - mass(Species("e"))true

Nuclide data

Two tables, both in src/nuclide_data.jl:

  • ELEMENTS — all 118 elements, standard atomic weights (IUPAC/CIAAW 2021 conventional values). Elements with no stable nuclide carry the mass number of their longest-lived isotope.
  • ISOTOPES — exact nuclide masses (AME2020), keyed by (symbol, mass number). Not the full nuclide chart: it covers the elements that come up in plasma chemistry and molecular spectroscopy. Adding one is a single line.

ELEMENT_ALIASES maps symbols that stand for a specific nuclide — D and T — so "D2" and "HT" resolve without a mass number.

julia> PlasmaSpecies.element(:D)²H
julia> mass(Species("D2")) / PlasmaSpecies.U_KG4.02820355568

Look-ups are element and isotope, both returning nothing for anything unknown.

Gases without a formula

A StringGas behaves like any other gas except that it cannot be weighed:

julia> mass(Species("Xyz"))ERROR: No mass available for Xyz: its label does not resolve to a chemical formula.
Check the spelling (symbols are case-sensitive, so `Co` is cobalt and `CO` is
carbon monoxide), or add the missing nuclide to `ISOTOPE_MASSES` in
src/nuclide_data.jl.

If a label needs a mass anyway, define a gas type and a mass method for it:

julia> struct UnknownGas <: PlasmaSpecies.Gas end
julia> PlasmaSpecies.mass(::UnknownGas) = π * 1e-26
julia> mass(Species(UnknownGas()))3.1415926535897934e-26
